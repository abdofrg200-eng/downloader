# VidGrab

تطبيق أندرويد لتحميل فيديو أو صوت من آلاف المواقع، بيشغّل yt-dlp و FFmpeg جوه الموبايل نفسه (من غير سيرفر).

## التشغيل
1. نزّل **Android Studio** (آخر إصدار) وافتح فولدر `VidGrab`.
2. استنى الـ Gradle Sync يخلص (لو طلب منك JDK 17 وافق).
3. وصّل موبايل (USB debugging) أو شغّل Emulator، واضغط **Run**.
4. لإخراج APK: `Build > Build APK(s)`.

## البناء على GitHub (من غير Android Studio)
1. ارفع المشروع على repo في فرع `main`.
2. روح تبويب **Actions** → هيشتغل workflow اسمه *Build APK* تلقائيًا (أو شغّله يدويًا من *Run workflow*).
3. لما يخلص، نزّل الـ APK من **Artifacts** (`VidGrab-debug-apk`).
4. لنشره للناس: اعمل tag بالشكل `v1.0` (`git tag v1.0 && git push --tags`) والـ APK هيتضاف تلقائيًا في **Releases**.

## الاستخدام
- الصق الرابط (أو اعمل Share لرابط من أي تطبيق → VidGrab).
- اضغط "جلب المعلومات" → اختار فيديو/صوت والجودة → "تحميل".
- الملفات بتتحفظ في `Downloads/VidGrab`.

## ملاحظات مهمة
- **تحديث yt-dlp:** المنصات بتغير آلياتها كتير. المكتبة بتيجي بنسخة yt-dlp مدمجة؛ حدّث رقم الإصدار في `app/build.gradle.kts` من وقت للتاني، وفكّر تضيف زرار تحديث من داخل التطبيق (`YoutubeDL.getInstance().updateYoutubeDL(...)` — راجع README مكتبة youtubedl-android للصيغة الحالية).
- محتوى DRM (نتفليكس وغيره) مش ممكن يتحمّل.
- التحميل بيكمل في الخلفية عن طريق Foreground Service، مع إشعار فيه نسبة التقدم وزر إلغاء (على أندرويد 13+ التطبيق هيطلب إذن الإشعارات).
- حاليًا بيتحمّل ملف واحد في المرة.
- التطبيقات دي غالباً مش بتتقبل على Google Play؛ التوزيع عادةً بيكون APK مباشر.
- حمّل بس المحتوى اللي ليك حق تحميله أو المسموح بيه، والتزم بشروط استخدام كل منصة.
